### 🚀 Minha Stack (resumo com foco)
- **Frontend:** Blazor (Server & WebAssembly) com MudBlazor para interfaces modernas e responsivas.
- **Backend:** ASP.NET Core com forte uso de **NHibernate + Oracle** para sistemas corporativos de alta complexidade. Também utilizo Entity Framework Core em cenários híbridos.
- **Autenticação & Segurança:** Identity, JWT, controle de permissões por perfil e versionamento de registros.
- **Bancos de Dados:** Oracle (principal), MySQL/MariaDB, SQL Server, MongoDB e Firebase (Auth/Firestore).
- **Mobile:** Flutter (Dart) para apps integrados ao backend com Firebase.
- **Cloud & Infra:** Azure, AWS, Nginx/Apache e integrações de CI/CD.
- **IoT & Visão Computacional:** OpenCV, LPR (reconhecimento de placas), controle de acesso facial e integrações com dispositivos (Control iD, Hikvision, Arduino).
- **Gestão & Documentação:** Swagger, Jira, Trello.
